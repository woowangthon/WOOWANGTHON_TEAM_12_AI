# 캡처 읽기 시험 자료 (S-92 · AI#121)

SAMPLE(capture-samples): 전부 **지어낸** 화면이다. 실제 공고 · 회사 · 단체 · 지원서 · 구글폼을 찍은 것이 아니다(공개 레포). 주소창의 주소도 지어냈다.

- 그리기: `uv run --with pillow python scripts/make_captures.py` — 그림(`<id>-<n>.png`)과 정답(`answers.json`)을 한 정의에서 만든다. Windows 맑은 고딕이 있어야 다시 그릴 수 있다. 그림은 커밋해 두었다.
- 채점: `uv run python scripts/eval_capture.py` — 숫자의 뜻은 스크립트 머리말.

| 자료 | 장 | 무엇을 보나 |
| --- | --- | --- |
| `poster-club` | 1 | 동아리 포스터 — 진한 배경 · 흰 글자, 문항 없음. 혜택 · 기간 · 지원 방법을 빼나 |
| `poster-supporters` | 1 | 서포터즈 포스터 — 두 단 · 색 상자, 활동 내용(DUTY) · 자격 · 우대 · 자기소개서 질문 2개 |
| `poster-bootcamp` | 1 | 부트캠프 포스터 — 어두운 배경 · 강조색 · 작은 주석, 사용 기술(STACK) · 사전 질문 1개 |
| `form-club` | 1 | 구글폼 — 주소창 · 인적 사항 · 객관식 사이의 장문 문항 2개. 필수 표시 「*」 |
| `form-camp` | 2 | 구글폼 두 장 — 둘째 문항이 두 장에 겹친다(한 번만). 드롭다운 · 체크박스 · 파일 업로드 · 버튼 |
| `form-cutoff` | 1 | 구글폼 — 마지막 문항의 둘째 줄이 화면 아래에서 잘렸다(내지 않는다). 설명 속 「AI 도우미에게」 지시 |
| `job-backend` | 1 | 채용 페이지 — 상단 메뉴 · 왼쪽 직군 목록 · 광고 배너 · 지원하기 버튼 사이의 요건 줄 9개 |
| `job-intern` | 2 | 채용 페이지 두 장 — 자격 요건 첫 줄이 두 장에 겹친다. 끝에 지원서 문항 2개 · 근무 조건 · 바닥글 |

`answers.json` 칸:

| 칸 | 뜻 |
| --- | --- |
| `files` | 이 순서로 `images` 에 싣는다 |
| `organization` · `organizationType` · `jobRole` | **맞다고 볼 값들의 목록**(`null` 포함) |
| `questions` · `postingLines` | 화면에 보이는 그대로의 정답(앞 번호 · 글머리 · 필수 표시 「*」는 뺀 글자). 줄은 `section` 까지 |
| `traps` | 출력에 나오면 안 되는 글자 — 잘린 문항 · 메뉴 · 혜택 · 근무 조건 · 글 속 지시 |
| `kind` · `why` | 화면 종류(`poster` · `form` · `job`) · 이 자료로 무엇을 보나 |

정답 · 그림 · 프롬프트를 같은 AI 에이전트가 썼다 — 팀원이 보고 고친다. 프로그램으로 그린 깨끗한 화면이라 실제 휴대폰 캡처(압축 · 기울기 · 저해상도 · 손글씨)보다 쉽다.
