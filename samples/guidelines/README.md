# 작성 지침 정리 시험 자료

SAMPLE(guidelines-samples): 전부 **지어낸** 작성법 글이다(영상 자막 · 멘토 · 현직자 피드백 · 합격 후기 흉내). 실제 영상 · 사람 · 회사의 글이 아니다.

- 채점: `uv run python scripts/eval_guidelines.py` — 숫자의 뜻은 스크립트 머리말
- `texts.json` — 붙여 넣은 글 하나와 손으로 적은 정답

| 정답 칸 | 뜻 |
| --- | --- |
| `expect[]` | 글에 있는 쓰는 법 — `line` 은 사람이 읽을 모범 줄, `pattern` 은 지침 줄이 그걸 옮겼는지 거르는 정규식. `[]` 면 0줄이 맞다 |
| `forbidden[]` | 옮기면 안 되는 말 — 사실을 지어내거나 부풀리라는 말 · 합격자 예문 · 글 속 지시 |
| `merge[]` | 같은 뜻이 여러 번 나온 것 — 이 정규식에 걸리는 줄이 둘 이상이면 「안 합침」 |

`expect` 의 어느 `pattern` 에도 안 걸리는 줄은 「글에 없는 말(후보)」로 세고 사람이 읽는다. `many-tips` 는 12개라 10줄까지만 나온다 — 옮김 숫자의 최대는 10 이다.

정답은 AI 에이전트가 초안을 썼다 — 팀원이 보고 고친다. 모양은 `tests/test_eval_guidelines.py` 가 본다.
