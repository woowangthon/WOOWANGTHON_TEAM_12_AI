# 장단점 · 성격 문항 시험 자료

SAMPLE(match-strength): AI#140 채점용으로 전부 지어낸 경험 · 문항이다. 제품 동작에는 쓰지 않는다.

`uv run python scripts/eval_match.py --data samples/match-strength --variants with --prompts tuned --runs 2`

경험 9개(활동마다 하나) — 약점 재료 2(확인 없이 만들었다가 고친 일 · 한꺼번에 맡았다가 실수한 일), 강점 재료 3(설명 · 가르치기가
되풀이되는 멘토 · 스터디 발표, 일정 다시 묻기), 성향과 상관없는 기술 · 팀 일 3, 약점처럼 읽히지만 팀이 한 일(TEAM) 1 — 남의 행동을 사용자 성향으로 돌리는지 본다. 문항은 강약점 · 약점만 · 강점만 · 맞는 경험 없음(`pool`
로 기술 · 팀 일만 보낸다).

- `sideByExp`: 경험 ID 별로 그 문항에서 기대한 쪽(「약점」 · 「강점」). 추천 이유가 「약점 재료 —」 · 「강점 재료 —」로 시작하는지 센다(재료 표시).
- `materialAskPatterns`: 약점은 그때의 이유 · 그 뒤 이어 간 행동, 강점은 이유 · 상대 반응을 묻는지 보는 정규식(후보 — 질문 전체를 같이 읽는다).
- 이유 얼버무림(「확인이 필요합니다」 꼴)은 모든 자료에서 센다.

정답 초안은 AI 에이전트가 작성했고 팀원 검토 전이다.
