# 이어짐 제안 시험 자료

SAMPLE(link-samples): 전부 **지어낸** 활동이다. 실제 사람 · 노트 · 단체가 아니다(공개 레포). `contract-example` 만 계약 예시(알고리즘 스터디 → 바꿔요) 그대로다.

- 채점: `uv run python scripts/eval_link.py` — 숫자의 뜻은 스크립트 머리말
- `inputs.json` — 자료마다 손으로 적은 정답

| 칸 | 뜻 |
| --- | --- |
| `request` | `/link-suggestions` 요청 그대로 |
| `linked` | 계기와 내용으로 닿는 후보 id — 찾아야 한다 |
| `maybe` | 골라도 틀렸다고 하지 않는 후보 id(해석이 갈린다) |
| `why` | 이 자료로 무엇을 보나 |

두 목록에 없는 후보를 고르면 억지 제안이다. 둘 다 빈 자료는 0개가 정답이다.

보는 것: 계약 예시 · 후보 여럿 중 하나 · 닿는 후보 둘 · 경험이 없는 후보 · 후보 20개(시간). 함정 — 이어짐이 없는 후보만(날짜 순서뿐) · 같은 낱말만 겹침(「스터디」) · 같은 분야일 뿐 · 계기 말고 경험만 비슷함 · 계기에 「때문에」가 적힌 경우(따라 단정하지 않나) · 글 속 지시를 따르지 않나.

정답과 프롬프트를 같은 AI 에이전트가 썼다 — 팀원이 보고 고친다. 실제 사용자 활동으로 잰 숫자가 아니다.
