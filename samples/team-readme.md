# 냉장고털이 🍳

> 2024 SW 중심대학 공동 해커톤 출품작 — 남은 재료로 만들 수 있는 요리를 추천합니다.

## 주요 기능

- 냉장고 사진으로 재료 인식
- 재료 조합별 레시피 추천
- 유통기한 임박 알림

## 기술 스택

| 영역 | 기술 |
| --- | --- |
| Frontend | React Native |
| Backend | Spring Boot, MySQL |
| AI | YOLOv8 |

## 팀원

| 이름 | 역할 |
| --- | --- |
| 김하늘 | 기획 · 발표 |
| 이도윤 | 프론트엔드 |
| 박서준 | 백엔드 · 배포 |
| 최유나 | 재료 인식 모델 |

## 실행

```bash
./gradlew bootRun
```

## 회고 한 줄

- 재료 인식이 어두운 사진에서 자주 틀려서, 촬영 화면에 밝기 안내 문구를 넣었다.
