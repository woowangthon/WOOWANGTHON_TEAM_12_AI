# 지원 나누기 시험 자료

SAMPLE(parse-samples): 전부 **지어낸** 글이다. 실제 공고 · 회사 · 단체 · 지원 문항이 아니다(공개 레포).

- 채점: `uv run python scripts/eval_parse.py` — 숫자의 뜻은 스크립트 머리말
- `inputs.json` — 글마다 손으로 적은 정답. `/parse-application` 의 `text` 로 보낸다

| 칸 | 뜻 |
| --- | --- |
| `text` | 붙여 넣은 글 |
| `organization` · `organizationType` · `jobRole` | **맞다고 볼 값들의 목록**(`null` 포함) — 여러 답이 말이 되면 다 적는다 |
| `questions` | 글에 적힌 문항, 글의 순서대로. 앞 번호 · 끝의 글자 수 안내는 채점에서 안 본다(스크립트 `same_question`) |
| `why` | 이 글로 무엇을 보나 |

보는 것: 문항 하나 · 여러 문항 · 여러 줄 문항 · 동아리 · 채용 · 부트캠프 · 인턴 · 서포터즈 · 비교과 · 공모전 · 문항이 없는 공고. 함정 — 자격 요건 · 제출 서류 · 자주 묻는 질문 · 사전 과제를 문항으로 만들지 않나, 여러 직무 공고에서 직무를 넘겨짚지 않나, 글 속 지시를 따르지 않나.

정답과 프롬프트를 같은 AI 에이전트가 썼다 — 팀원이 보고 고친다. 실제 공고로 잰 숫자가 아니다.
