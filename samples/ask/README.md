# 꺼내기 시험 자료

SAMPLE(ask-samples): 전부 **지어낸** 한 줄 질문이다. 경험은 매칭 자료(`../match/experiences.json` — 지어낸 사용자 한 명)를 그대로 쓴다.

- 채점: `uv run python scripts/eval_ask.py` — 숫자의 뜻은 스크립트 머리말
- `queries.json` — 질문과 손으로 적은 정답

| 정답 칸 | 뜻 |
| --- | --- |
| `kind` | `match` 맞는 경험이 있다 · `none` 맞는 경험이 없다(0개여야 한다) |
| `good` | 첫 추천으로 맞는 경험 |
| `ok` | 추천해도 되는 경험 |
| `bad` | 추천하면 틀린 경험 |
| `allowZero` | 0개도 맞음 — 내 일로 찾는데 팀원이 한 일만 있는 질문(`deploy` · `budget`). 이때 `ok` 를 첫 추천으로 내도 맞다 |

보는 것: 맞는 게 없으면 0개인가 · `TEAM` · `UNKNOWN` 경험(102 · 103 · 114 · 132)을 「내가 한 일」로 말하나 · 근거에 없는 수치를 붙이나 · 보완 321 을 근거로 쓰나.

정답은 AI 에이전트가 초안을 썼다 — 팀원이 보고 고친다. ID 가 실제 경험을 가리키는지는 `tests/test_eval_ask.py` 가 본다.
