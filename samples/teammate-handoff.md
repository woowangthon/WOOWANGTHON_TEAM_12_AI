# 한결 → 서윤: 「모여라」 중간 발표 원고 (내 파트 + 소감)

━━ 1. 내 파트 ━━

- 출석 체크 API: QR 코드를 찍으면 출석이 기록되게 만들었다. 같은 학생이 두 번 찍으면 처음 기록만 남긴다.
- 알림: 모임 시작 10분 전에 푸시를 보내게 했다.

━━ 2. 소감 ━━

제가 맡은 출석 API 를 서윤 님이 실제 폰으로 돌려 보다가 중복 기록 버그를 찾아 줬고, 저도 서윤 님 화면 코드를 읽고 로딩이 두 번 뜨는 문제를 찾았습니다. 문서로 먼저 합의하고 나눠 짠 덕분에 셋이 동시에 작업해도 덜 부딪혔다고 느꼈습니다.
