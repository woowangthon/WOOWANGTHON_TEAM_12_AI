# 하루가계

혼자 만든 개인 프로젝트. 영수증 사진을 찍으면 항목을 읽어 가계부에 넣어 주는 안드로이드 앱.

## 기능

- 영수증 사진에서 가게 이름 · 날짜 · 금액 읽기 (ML Kit 글자 인식)
- 읽은 값을 사용자가 고친 뒤 저장
- 달마다 분류별 지출 그래프

## 만들면서

- 처음엔 글자 인식 결과를 그대로 저장했는데, 금액을 자주 잘못 읽어서 저장 전에 확인 화면을 넣었다.
- Room 으로 기기 안에만 저장한다. 서버는 두지 않았다.
- Jetpack Compose 를 이 프로젝트에서 처음 써 봤다.

## 기술

Kotlin · Jetpack Compose · Room · ML Kit
